- Do not add unnecessary dependencies.
- Ask before making destructive, security-sensitive, migration, dependency upgrade, secret, credential, or network-related changes.

## Definition Of Done

- Meaningful tests are added or updated.
- Tests cover the stated behavior and important edge cases.
- Production code is unchanged unless explicitly required.
- Available checks pass, or any unavailable checks are reported.
