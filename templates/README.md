# Templates

Reusable task briefs for common coding-agent work.

## Choose A Template

- Use `bugfix.md` when behavior is wrong and should be corrected.
- Use `feature.md` when adding scoped functionality.
- Use `refactor.md` when changing structure while preserving behavior.
- Use `test-generation.md` when adding or improving test coverage.
- Use `documentation.md` when creating or updating docs.
- Use `repository-onboarding.md` to discover and approve project-specific agent instructions.

## How To Use

1. Copy the template into an agent prompt, issue, pull request description, or task tracker.
2. Fill in the task, context, constraints, definition of done, and commands.
3. Remove sections that are not relevant.
4. Keep the expected final response aligned with `AGENTS.md`.

Templates should make the task clearer without replacing the default working loop.
