# Loop Recipes

Operational workflows for common coding-agent tasks.

Use a recipe when you want more than a task template. Recipes define when to use the workflow, the loop steps, checks, stop conditions, approval points, and the expected final response.

## Recipes

- `bugfix-loop.md` for correcting reproducible behavior.
- `failing-test-loop.md` for making a failing check green.
- `refactor-loop.md` for preserving behavior while improving structure.
- `pr-review-loop.md` for reviewing diffs and pull requests.
- `documentation-loop.md` for docs grounded in real project files.
- `test-generation-loop.md` for adding focused coverage.
