# Snippets

Copy-pasteable sections for real `AGENTS.md` files.

## Files

- `default-loop.md` defines the standard inspect, edit, check, retry, stop loop.
- `approval-rules.md` separates routine work from ask-first actions.
- `stop-conditions.md` defines when an agent should stop.
- `final-response-format.md` standardizes handoffs.
- `testing-policy.md` defines when to add or update tests.
- `security-guardrails.md` adds safety rules for sensitive repositories.
- `large-refactor-policy.md` keeps broad refactors controlled.

Use only the snippets that fit the target repository. Concrete repo-specific commands belong in `AGENTS.md`.
