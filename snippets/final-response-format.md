# Final Response Format

Use this section in `AGENTS.md` to standardize handoffs.

```md
## Final Response Format

Final responses must include:

- Summary: What changed and why.
- Files changed: List the important files touched.
- Checks run: Commands run and whether they passed, failed, or were unavailable.
- Remaining risks or follow-ups: Anything not verified, deferred, or needing human review.

For reviews, put findings first and order them by severity.
For blocked work, explain the blocker and the next useful action.
```
