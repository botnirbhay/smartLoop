# Durable Learning

Use this section when agents may improve repository instructions during normal work.

```md
## Durable Learning

- Do not edit `AGENTS.md` to record task history or every completed change.
- Update it only for a stable repository-wide command, boundary, convention, or prerequisite that is missing or incorrect.
- Verify the fact from a source-of-truth file such as a manifest, CI workflow, task runner, architecture decision, or maintained project document.
- Keep the update concise and actionable for future tasks.
- Never record guesses, transient failures, secrets, personal data, local machine paths, or generated state.
- Never weaken checks or approval guardrails to make the current task easier.
```
