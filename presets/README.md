# Presets

Complete `AGENTS.md` starting points for new or lightly documented repositories.

- [Minimal](minimal/AGENTS.md) uses placeholders for any stack.
- [Node.js](node/AGENTS.md) uses package scripts discovered in `package.json`.
- [Python](python/AGENTS.md) uses tools configured by the repository.
- [Go](go/AGENTS.md) starts with standard Go tooling.
- [Rust](rust/AGENTS.md) starts with Cargo tooling.

## Use A Preset

1. Copy one preset to the target repository root as `AGENTS.md`.
2. Replace every angle-bracket placeholder.
3. Remove commands and paths the repository does not support.
4. Add project-specific architecture and approval rules.
5. Run [Test Your Setup](../docs/test-your-setup.md).

Presets are starting points, not evidence that a command exists. For an established repository, prefer the discovery workflow in [Bootstrap Your Repository](../docs/bootstrap-your-repo.md).
