The fictional `package.json` defines:

- `test`: runs the full Vitest suite.
- `test:notes`: runs tests under `test/notes/`.

- `typecheck`: runs TypeScript without emitting files.


- `src/generated/` is generated by an internal schema command.
- `prisma/migrations/` changes persisted data and needs human review.
- `src/auth/` is security-sensitive.
- Integration tests require a database service.
- Dependency changes modify `package-lock.json`.
