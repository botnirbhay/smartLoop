# Worked Adoption Example

This fictional example shows how a team could apply the kit to an existing Node.js service without copying the whole repository.

Read the files in order:

1. [Repository Summary](repository-summary.md) describes the facts available during discovery.
2. [Discovery Report](discovery-report.md) turns those facts into a proposal for human review.
3. [Final AGENTS.md](final-AGENTS.md) is the approved repository policy.
4. [Example Task](example-task.md) shows how short a task prompt becomes.
5. [Expected Final Response](expected-final-response.md) shows the resulting handoff.

The project and commands are illustrative. In a real repository, every command must come from that repository's files or documentation.
