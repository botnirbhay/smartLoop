# Examples

This directory contains starter policy and stack examples you can copy into `AGENTS.md` or adapt for a specific repository.

## Files

- `approval-rules.md` defines actions an agent may take freely and actions that require approval.
- `check-commands.md` lists common verification commands by stack.
- `stop-conditions.md` defines when an agent should finish or report a blocker.
- `languages/` contains Node.js, Python, Go, and Rust examples.
- `adoption/` shows an end-to-end repository onboarding example.

## How To Use

1. Start with the examples that match your project.
2. Delete commands and policies that do not apply.
3. Move the final project-specific rules into `AGENTS.md`.
4. Keep these files as reference material if they remain useful.

Examples are not requirements. The active project policy should live in `AGENTS.md`.
