# Go Example

Use this as a starting point for Go repositories. Keep only the commands your repo actually supports.

## Typical Check Command

```sh
go test ./...
```

## Lint Command

```sh
go vet ./...
```

## Format Command

```sh
gofmt -w .
```

## Test Command

```sh
go test ./...
```

## Sample `AGENTS.md` Snippet

```md
## Go Checks

Use standard Go tooling unless the repo documents a wrapper command.

Preferred commands:

- `go test ./...` for tests.
- `go vet ./...` for static checks.
- `gofmt -w <changed files>` before final verification.

Run package-level tests first when the changed area is small, then `go test ./...` for shared changes.
```

## Common Gotchas

- `go test ./...` may run integration tests in some repos.
- Use `gofmt` on changed Go files, not broad unrelated cleanup.
- Generated files should usually be regenerated by the documented tool, not edited by hand.
- Module or dependency changes affect `go.mod` and `go.sum` and should be reviewed.
- Tests may depend on build tags.
